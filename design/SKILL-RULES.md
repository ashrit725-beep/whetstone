### Hard bans
- Background #F4F1EA or any warm cream in the range #F2EFE8-#FAF7F0, in either theme — frontend-design names near-#F4F1EA cream the #1 generated-design tell.
- Accent #D97757 or any terracotta/warm-clay hue in the 10-30 deg hue range used as a primary or secondary accent — frontend-design flags #D97757 by name as Anthropic's own accent and therefore a tell. This also bans brand-guidelines' Orange #d97757, its Blue #6a9bcc, and its Green #788c5d as Whetstone accents.
- Tinted near-black grounds #0B0B0B, #111111, #1e1e1e, or #141413 as the dark base — named as template chrome. Whetstone's dark ground is #141D20 and carries a measurable blue-green cast (B channel 32 > R channel 20).
- Tracked-out ALL-CAPS eyebrow labels above any heading anywhere (no `text-transform: uppercase` + `letter-spacing` combination in the codebase except inside the grit-number chip glyphs, which are numerals).
- Meta strings joined with middle dots: no `·` or `•` as a separator in author/date/stage/count strings. Use a `<dl>` with visible `<dt>` labels or separate flex items with 0.75rem gaps.
- `WORD — fragment` label constructions with a spaced em dash.
- A trailing `→`, `->`, or `»` appended to link or button text. Arrow glyphs only inside a `<svg>` that has `aria-hidden="true"` and only on pagination/carousel controls.
- A monospace typeface for metadata, stats, timestamps, counts, ratings, or small labels. JetBrains Mono is permitted only inside `<pre><code>` blocks and inline `<code>` in project descriptions and feedback bodies.
- Accenting one word of a headline in a different color, italic, or weight. Headline emphasis is done with the Archivo width axis across the whole line, not one word.
- `border-radius` applied uniformly: no single radius value used on buttons, cards, inputs, and modals alike. Radius is hierarchical (see concrete_values) and `border-radius: 9999px` / `rounded-full` is forbidden on every element except `<img>` avatars.
- `box-shadow: 0 Npx Npx rgba(0,0,0,0.1)` or any soft grey shadow under cards, chips, or feed rows. The dark theme has exactly one shadow token and it is used only on overlays.
- Gradient washes as decoration: no `linear-gradient` or `radial-gradient` in any background except the single `mask-image` fade on the grit-scale hatch bar.
- Identical rounded cards in a 3-across grid as the landing page's structural device (the SaaS-card kit). The landing page has no 3-card feature row.
- `01 / 02 / 03` numbered markers. The only numbers allowed as ordinal markers are the real grit values 120 / 400 / 1000 / 3000 / 8000, because project stage genuinely is a coarse-to-fine sequence.
- Scroll-triggered fade-and-slide-up on section entry, and hover lift/scale/shadow on feed cards or project cards. No `transform: translateY()` tied to IntersectionObserver anywhere.
- Inter, Roboto, Open Sans, Poppins, Lora, DejaVu Sans, DejaVu Serif, FreeSans, FreeSerif, and `system-ui` as a display or body face — the last five are theme-factory's literal prescriptions and are Linux metric-substitute fonts with no web license story or variable axes.
- Emoji as UI iconography (no 🔥, ⭐, 🚀, ✨ in ratings, stage chips, empty states, or CTAs).
- Hype copy: the strings "revolutionize", "unleash", "supercharge", "game-changing", "seamless", "effortless", "10x", "AI-powered" must not appear in any rendered string in the repo.
- Star-rating widgets rendered as five identical outline stars. Whetstone's rating primitive is the grit bar (see applied_to_whetstone).
- `outline: none` on any focusable element without a same-rule replacement `:focus-visible` treatment.
- Placeholder text used as the only label on any input in the feedback composer or auth forms.
- Disabled submit buttons as the validation strategy in the feedback composer and auth — the button stays enabled and explains what is missing on press.

### Hard bans
- `transition: all` anywhere, including Tailwind's `transition-all` utility — WIG lists it twice (Animation + Anti-patterns). Every transition must name properties: `transition-[transform,opacity]`.
- Animating any property other than `transform` and `opacity`. No transitioning `width`, `height`, `top`, `left`, `margin`, `background-position`, `box-shadow`, or `filter` (WIG: compositor-friendly only).
- `outline-none` / `outline: none` on any focusable element without a `focus-visible:` replacement in the same class string. Also banned: styling `:focus` instead of `:focus-visible`.
- `<div onClick>` and `<span onClick>`. Actions use `<button>`; navigation uses `<a>`/next/link `<Link>` so Cmd-click and middle-click work.
- `user-scalable=no` or `maximum-scale=1` in the Next.js `viewport` export.
- `onPaste` handlers that call `preventDefault()` — banned on every field including the auth OTP/code input.
- Literal `...` and straight quotes `"` `'` in any user-visible string. Use `…`, `“`, `”`, `’`.
- Animated GIF for any motion asset (project demo loops, empty-state art). Use `<video autoplay muted loop playsinline>` with a still poster.
- `<img>` or `next/image` without explicit `width` and `height` (CLS).
- `.map()` over an unbounded array in the Discover feed, feedback thread, or dashboard inbox with no `virtua` virtualization and no `content-visibility: auto`. WIG threshold: >50 items.
- Reading layout during render: `getBoundingClientRect`, `offsetHeight`, `offsetWidth`, `offsetTop`, `scrollTop`, `getComputedStyle` in a component body or `useMemo`.
- Hardcoded date/number formatting: `toLocaleDateString('en-US', {...})` with a fixed locale string, template-literal `${m}/${d}/${y}`, `.toFixed(1) + '/5'` for ratings. Use `Intl.DateTimeFormat` / `Intl.NumberFormat` / `Intl.RelativeTimeFormat`.
- Defining a component inside another component (`const Row = () => ...` inside `FeedbackThread`). Causes remount, focus loss in the composer textarea, and effect re-runs (react-best-practices `rerender-no-inline-components`, HIGH).
- `forwardRef` — banned under React 19 (composition-patterns `react19-no-forwardref`). `ref` is a plain prop.
- `useContext(X)` — use `use(X)` (same rule).
- Boolean mode props on shared components: no `isEditing`, `isThread`, `isPaid`, `isBounty`, `compact`, `showRatings` on `<FeedbackComposer>` or `<ProjectCard>` (composition-patterns `architecture-avoid-boolean-props`, CRITICAL).
- `renderHeader` / `renderFooter` / `renderActions` props. Use `children` (composition-patterns `patterns-children-over-render-props`). Render props are allowed ONLY where the parent passes data down, e.g. `renderItem={({item, index}) => ...}` on the virtualized feed.
- `{count && <Badge>{count}</Badge>}` — renders a literal `0` for a project with 0 reviews. Ternary only (`rendering-conditional-render`).
- `useMemo` wrapping a simple expression with a primitive result, e.g. `useMemo(() => a.isLoading || b.isLoading, [...])` (`rerender-simple-expression-in-memo`).
- Module-level mutable request state in any RSC/route handler: `let currentUser = null` then assigning in a page. Causes cross-request data leaks under concurrent renders (`server-no-shared-module-state`, HIGH).
- A `'use server'` action with no `verifySession()` + authorization check inside the function body. Middleware/layout guards do not count — Server Actions are public endpoints (`server-auth-actions`, CRITICAL).
- Static top-level `import { Analytics } from '@vercel/analytics/react'` in the root layout (`bundle-defer-third-party`).
- `export * from './...'` barrel files inside `components/` or `lib/`, and deep manual imports like `lucide-react/dist/esm/icons/check` (implicit `any` under `strict`).
- `suppressHydrationWarning` on anything except the specific node rendering a server/client-divergent timestamp (`rendering-hydration-suppress-warning`).
- An `<input>` / `<textarea>` with `value` and no `onChange` (hydration-safety rule).
- `autoFocus` on any mobile viewport, and on any screen with more than one primary input. Permitted only on desktop sign-in email field and the search box on Discover.
- Immediate destructive actions: deleting a feedback thread, withdrawing a bounty, or unpublishing a project without a confirmation modal or an undo window.

### Concrete values
- --dur-micro: 100ms (toggle/checkbox tick — component-reference animation.md)
- --dur-hover: 140ms (skill range 100-150ms; scroll-craft `--sc-d-fast` is 160ms, take the tighter 140ms)
- --dur-exit: 160ms (exits run 25-35% faster than enters; 220ms × 0.73 = 160ms)
- --dur-enter: 220ms (inside the 200-300ms entrance band; matches scroll-craft's reduced-motion 220ms so the two states share one number)
- --dur-overlay: 250ms (modal/drawer enter; exit 180ms — component-reference animation.md recipe 9)
- --dur-move: 400ms (shared-element morph and directional slide travel — react-view-transitions css-recipes.md `--duration-move`; also the absolute ceiling)
- --dur-count: 1400ms (scroll-craft `data-sc-count-ms` default; skill band 1.2-1.8s, charts.md says 1-1.5s)
- --ease-out: cubic-bezier(0.23, 1, 0.32, 1) — scroll-craft `--sc-ease-out`, the page-wide standard for entering and hover
- --ease-in: cubic-bezier(0.4, 0, 1, 1) — exits only (component-reference animation.md 'Acceleration')
- --ease-standard: cubic-bezier(0.4, 0, 0.2, 1) — on-screen position moves
- --ease-energetic: cubic-bezier(0.16, 1, 0.3, 1) — reserved for exactly one element per page
- --ease-indicator: cubic-bezier(0.5, 0, 0.2, 1) at 220ms — tab underline / segmented pill group, verbatim from react-view-transitions css-recipes.md Sliding Indicator
- Entrance offset: translateY(10px) for app surfaces, 14px for marketing sections (scroll-craft ships 14px). A fade with no rise reads as a loading glitch; a rise past 24px reads as a slide — 24px is the hard ceiling.
- Stagger: 40ms per child, hard stop at 300ms total (max 8 staggered children)
- Hover micro on cards: box-shadow + border-color only, ≤1px translate, 140ms. Never scale.
- Press: scale(0.97) or translateY(1px), 120ms
- Focus ring: `outline: 2px solid var(--accent); outline-offset: 3px; border-radius: 6px` (scroll-craft scrollcraft.css `:focus-visible`)
- Radius scale (hold it, never uniform): 6px inputs/buttons/badges · 12px cards · 20px modals/sheets · 999px pills only. Child radius ≤ parent radius.
- Parallax: total travel ≤200px per layer; adjacent planes differ by 10-30% of scroll rate; copy rides at exactly 1.0x (scroll-craft devices.md §6 + hero-depth.md, measured off a reference premium hero at 31% / 17% / 20% / 1x)
- Scroll-scrub playhead lerp: 0.18 per frame, clamped 0.02-1.0, never 0; seek deadband 8ms desktop / 20ms mobile; 1.0 (no smoothing) under reduced motion (scroll-craft scrollcraft.js)
- Pointer interpolation constants: tilt 0.09/frame, magnet 0.12/frame, tilt max 5-9deg (past 12deg it is a toy), magnet factor 0.20-0.35, perspective 1100px (scroll-craft scrollcraft.js + devices.md §9)
- Toast: translateY(14px)→0 + fade, 200ms, `role="status"`, auto-dismiss ≥5000ms
- Tooltip: 400ms open delay (Radix `delayDuration`), 150-200ms fade, no interactive content inside
- Accordion / disclosure: 200ms height 0↔auto via `interpolate-size` or a CSS var
- Chart motion: bar grow 400-600ms · line draw 600-800ms · hover 150ms · series stagger 80-150ms offset, ≤5 series, ≤1200ms total · sibling dim to opacity 0.3
- Scroll-reveal via CSS scroll-driven animations: `animation-timeline: view(); animation-range: entry 0% entry 40%`, wrapped in `@supports (animation-timeline: view)` AND `@media (prefers-reduced-motion: no-preference)`
- IntersectionObserver reveal trigger: `rootMargin: '0px 0px -12% 0px'`, `threshold: 0.01`; count-up trigger `threshold: 0.5` with `rootMargin: '0px 0px -10% 0px'`
- Contrast floors, measured on the composited render: body text ≥4.5:1, large text ≥3:1, controls and focus indicators ≥3:1 (WCAG 2.2 AA)
- Grain/atmosphere overlay: 4.5% opacity fixed layer (scroll-craft `.sc-grain { opacity: 0.045 }`) — prevents banding on a dark ground without being a visible effect
- Elevation: exactly three steps, every shadow carries an offset AND a blur AND is tinted to the canvas hue (scroll-craft `--sc-e1/e2/e3`, shadow-color `hsl(220 40% 2%)`)
- Mobile breakpoint for motion decisions: 860px (scroll-craft's `smallMQ`) — below it, corner scrims become full-width bands and pointer devices are off
- Heights: `100svh` above-the-fold, `100dvh` immersive shells, always with a `min-height:100vh` fallback first
- Display fonts that are not Inter (Inter is the AI-page default and reads as a non-decision): Geist, Archivo, Outfit, Satoshi, Cabinet Grotesk, Instrument Sans, Space Grotesk. Two families maximum, 2-3 weights (400/500/600).

- Hype and filler vocabulary in any rendered string: seamless, elevate, unleash, supercharge, revolutionary, next-generation, game-changing, best-in-class, leverage, unlock, streamline, robust, 'In today's fast-paced world', 'Say goodbye to'. refero copywriting 'Banned Words'; taste-skill 9.D 'filler verbs'.

### Concrete values
- Type scale — refero typography §2 Minor Third (1.200) off a 16px base, capped at 6-8 sizes in production: 11px / 13px / 16px / 19px / 23px / 28px / 33px / 40px, i.e. --text-xs 0.6875rem, --text-sm 0.8125rem, --text-base 1rem, --text-lg 1.1875rem, --text-xl 1.4375rem, --text-2xl 1.75rem, --text-3xl 2.0625rem, --text-4xl 2.5rem. Landing hero may add --text-5xl 3rem and --text-6xl 3.5625rem (48px / 57px).
- Font weights — exactly three loaded: 400 body, 500 UI labels, 600 buttons and subheads. refero typography §5 and §12: '≤3 weights per family', 'body text always 400, never bold entire paragraphs'.
- Line heights — --leading-none 1, --leading-tight 1.15, --leading-snug 1.3, --leading-normal 1.55, --leading-relaxed 1.7. Body 1.5-1.7, headlines 1.0-1.2, UI text 1.2-1.4, buttons 1. refero typography §6.
- Letter spacing — --tracking-tighter -0.02em (48px+ display), --tracking-tight -0.01em (32px+ headings), --tracking-normal 0 (body 14-18px), --tracking-wide 0.015em (11-13px small text, REQUIRED), --tracking-wider 0.02em (UI labels and buttons, REQUIRED), --tracking-caps 0.08em (ALL CAPS, MANDATORY, floor 0.06em). refero typography §8.
- Italic descender clearance — any italic word containing y g j p q in display type needs `leading-[1.1]` minimum plus `pb-1`. taste-skill 4.1; `leading-none` clips.
- Motion durations — --duration-fast 120ms (hover, press, focus, tooltip), --duration-default 200ms (accordion, tabs, small panel, list row enter), --duration-slow 320ms (modal, drawer, route). Instant band 90-150ms, state change 160-240ms, page/large 240-360ms. Nothing in product UI exceeds 500ms. refero motion §2 and §5.
- Motion easings — --ease-out cubic-bezier(0.0, 0.0, 0.2, 1) for enter, --ease-in cubic-bezier(0.4, 0.0, 1, 1) for exit, --ease-in-out cubic-bezier(0.4, 0.0, 0.2, 1) for state change, --ease-emphasized cubic-bezier(0.2, 0.0, 0, 1). Marketing scroll-entry uses cubic-bezier(0.16, 1, 0.3, 1) at 600ms (minimalist §7 / taste-skill 5.C). Zero `linear` easing anywhere (refero motion §8).
- Motion distances — --motion-distance-xs 2px, -sm 4px, -md 8px, -lg 16px, -xl 24px. List row enter is fade + translateY 4-8px over 200ms; row remove is fade + collapse over 180ms. refero motion §4 and Appendix.
- Spring parameters (Motion library) — snappy { stiffness: 400, damping: 30 }; smooth { stiffness: 200, damping: 20 }; taste-skill 5 gives { type: 'spring', stiffness: 100, damping: 20 } for reveal moments. Spring must decay fast; no prolonged oscillation.
- Press feedback — `transform: scale(0.98)` over 90-120ms (refero motion §4, minimalist §7), or `-translate-y-[1px]` (taste-skill 4.5). Pick one and use it on every button in the product.
- Reduced-motion overrides — --duration-fast 0ms, --duration-default 0ms, --duration-slow 100ms, --duration-slower 100ms, --motion-distance-sm/md/lg 0px, plus the blanket `animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important`. refero motion §6 and Appendix.
- Spacing scale derived by refero typography §7's rule (line-height x 0.5 = minimum step; 16px / 1.55 rounds to a 24px line box, so the step is 12px): 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px. Section padding for product surfaces py-16 to py-24 (taste-skill §7 VISUAL_DENSITY 4-7); landing sections py-24 to py-32 (minimalist §8, soft-skill §4.C).
- Color distribution — 60-80% neutral surfaces and borders, 10-20% text hierarchy, 5-10% accent and semantic. Maximum 2 colors per component. refero color §3.
- Dark theme neutrals for Whetstone (cool-tinted, not pure gray, per senlin step1 category 14) — --color-bg #0E1113, --color-surface-1 #16191C, --color-surface-2 #1D2125, --color-surface-3 #24282C, --color-text #F2F4F5 (17.17:1 on bg), --color-text-muted #A2ABB2 (8.12:1 on bg, 6.95:1 on surface-2), --color-text-subtle #7C858C (5.04:1 on bg, above the 4.5:1 body floor), --color-border rgba(255,255,255,0.09) for decorative dividers, --color-border-control #606870 (3.35:1 on bg) and #6E767D (3.51:1 on surface-2) for input and control boundaries so they pass WCAG 1.4.11 at 3:1.
- Light theme neutrals — --color-bg #FBFBFA, --color-surface-1 #FFFFFF, --color-surface-2 #F4F5F6, --color-text #1A1D1F (16.36:1), --color-text-muted #3F464B (9.26:1), --color-text-subtle #5B646B (5.83:1), --color-border rgba(0,0,0,0.08), --color-border-control #767D84 (4.17:1 on white). Written as a separate ramp, not an inversion (refero color §5).
- Accent — burnt orange, in both refero's safe-alternative list (#ea580c) and taste-skill 4.2's list (Burnt Orange), and outside the banned purple band. Dark theme: --color-accent #FF7A2F (7.29:1 as text on #0E1113; 6.79:1 on surface-1) with --color-on-accent #0E1113 (7.29:1 ink on the solid button; white on orange would be 3.56:1 and fail). Light theme: --color-accent #C2410C (5.00:1 as text on #FBFBFA) with --color-on-accent #FFFFFF (5.18:1). --color-accent-tint rgba(255,122,47,0.14) dark / #FDEBE1 light.
- Semantic colors, dark — --color-success #34D399 (9.86:1), --color-danger #F87171 (6.85:1), --color-warning #FBBF24 (11.35:1), --color-info #38BDF8 (8.85:1). Light — --color-success #166534 (6.89:1), --color-danger #B91C1C (6.25:1), --color-warning #A16207 (4.75:1), --color-info #0369A1 (5.73:1). Note #16A34A measures 3.18:1 on #FBFBFA and fails as body text — do not use refero color §6's default success value in light mode.
- Semantics ship as 4-token sets, not single hexes: --success, --success-bg, --success-border, --on-success. refero color §2.3.
- Radius scale (one documented system, taste-skill 4.4) — 10px cards and panels, 8px inputs/selects/buttons, 6px elements nested inside a 10px container (concentric, per senlin step1 category 16), 9999px for status chips and avatars only. minimalist §5 caps card radius at 8-12px and bans full-pill primary buttons.
- Shadows — dark theme uses zero shadows; elevation is a lighter surface step plus a 1px rgba(255,255,255,0.09) border. Light theme uses one hover shadow only: `0 2px 8px rgba(0,0,0,0.04)` transitioning in over 200ms from `0 0 0` (minimalist §7), opacity capped below 0.05 (minimalist §2), hue-tinted toward the background rather than pure black (taste-skill 4.4).
- Icon sizes — 16px inline with body text and in table cells, 20px in buttons and nav, 24px in form inputs, 28-32px in empty states. Icon paired to text: 14-16px text → 16px icon; 16-18px → 18-20px; headings → 20-24px. Meaningful icons need 3:1 contrast; icon buttons need 44x44 touch / 32x32 desktop hit area. refero icons.md.
- Contrast floors — 4.5:1 body text at or below 16px, 3:1 large text (18px+ bold or 24px+ regular), 3:1 non-text UI components and icons, 24x24 CSS px minimum target (WCAG 2.2 SC 2.5.8). refero color §4, icons.md, craft-details.
- Line length — optimal 50-75 characters (500-700px at 16px), minimum 45ch, maximum 85ch. refero typography §9.
- Grid and container — 12 columns, 24px gutter, `max-w-[1400px] mx-auto` or `max-w-7xl` page container; prose column `max-w-4xl`/`max-w-5xl` (minimalist §8). Breakpoints sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536 (taste-skill 3.E). Responsive verification at 320px, 768px, 1440px (refero typography §15).
- Fluid type for the landing hero — `clamp(2rem, 5vw + 1rem, 3.5rem)`; base `clamp(1rem, 1.5vw + 0.5rem, 1.25rem)`. refero typography §11.
- Counting limits that act as lint rules — ≤8 font sizes, ≤4 text colors, ≤4 weights (refero typography §13 'Quick Test'); 1-2 accent colors (refero color §9); 2 colors max per component; ≤2 font families, 1 preferred; ≤3 weights loaded; `font-display: swap` on every face.
- Virtualization threshold 50 items; CSS fallback `content-visibility: auto; contain-intrinsic-size: 0 <estimated-row-height>px`. craft-details §5.
- Placeholder image source when no real asset exists — `https://picsum.photos/seed/{descriptive-seed}/{w}/{h}` with a seed that names the section; real brand logos from `https://cdn.simpleicons.org/{slug}/{hex}`. taste-skill 4.8.
- Landing-page hard caps — hero headline ≤2 lines, subtext ≤20 words and ≤4 lines, ≤4 text elements in the hero, hero top padding ≤pt-24, nav height 64-72px default and 80px absolute max on one line, section headline ≤8 words, section sub-paragraph ≤25 words, testimonial quote ≤3 lines, ≥4 distinct layout families across 8 sections, ≤2 consecutive image+text split sections. taste-skill 4.7, 4.9, 4.10.

- Input geometry: border 1px in every state; `outline: 2px solid transparent` reserved at rest; hover shifts background 4–6% darker; disabled = opacity 0.55 + cursor: not-allowed + aria-disabled="true"; helper container min-height: 1lh; ~24px right-edge slot reserved permanently; vertical padding = (height − line-height-px) / 2; textarea min-height 6rem with resize: vertical.

- Motion micro-recipes: CTA hover translateY(-1.5px) 200ms --ease-out, active at 60ms; card lift translateY(-3px) 180ms; button press scale(0.98)/translateY(1px) 100ms in, 150ms out; modal scale 0.96 → 1.0 + opacity over 300ms --ease-out, close 220ms --ease-in scale 1.0 → 0.98; dropdown open 180ms / close 140ms, ≤8 items may stagger 30ms; tab underline translateX 250ms; command-palette highlight 120ms; number counter 1.2–1.6s (or 400ms on data update); marquee 40–60s infinite, pause on hover; page-load stagger 60ms × DOM index, capped ~500ms total.
- Spring configs (physical interactions only): 50/20 gentle · 180/22 snappy drag-release · 280/26 stiff picker-snap · 400/40 position correction.
- Breakpoints (rem-based, min-width direction only): 40rem (~640px, typography breakpoint — display steps down, side labels go inline), 60rem (~960px, layout breakpoint — multi-column collapses, sticky unsticks, tilts drop), 90rem (~1440px). Mobile floor viewports to verify: 320 / 375 / 414 / 768px. Hero fold test at 1280×800.
- Container padding: padding-inline: clamp(1rem, 4vw, 1.5rem) minimum so content never kisses the edge; clamp(1rem, 4vw, 4rem) for wide containers.
- Hero footprint: min-height: clamp(60vh, 75dvh, 88dvh) — 70–90% of the first viewport. padding-block-end ≥ 1.3 × padding-block-start. At most TWO centred elements; the eyebrow or CTA breaks axis.
- Rule/radius tokens: --rule-hair 0.5px, --rule-fine 1px, --radius-card / --radius-pill / --radius-input per theme. Playful ceiling: 12px cards, 8px inputs, 999px pills. Modern-minimal: 8px cards with a 1px border. Cobalt register: 6px.
- Icons: sizes 16/20/24/32 only; stroke 2px (2.5px only below 20px); currentColor. Canon: Lucide (1,600+, 2026 default), Phosphor (9,000+, 6 weights), Heroicons (~300, Tailwind projects), Tabler (5,900+, 24×24 grid), Iconoir (~1,500). Logo walls: monochrome, 32–48px height-aligned, gutter = 2–3× logo height; Simple Icons / SVGL as source.
- Grain recipe (E7, the only permitted ambient texture): two-stop linear-gradient at 135° with both stops < 0.04 chroma, plus SVG feTurbulence baseFrequency="0.9" numOctaves="2" at opacity 0.06, mix-blend-mode: multiply, hero-only — never page-wide.
- Highlighter band geometry: linear-gradient(180deg, transparent ~38%, accent ~38%, accent ~92%, transparent ~92%) — sits behind the x-height, not the baseline. Underlines 1–2px, offset 1–2px, never 5+px.
- Enrichment tier hierarchy: 0 typography-only (default) → A pure CSS art → B hand-built SVG → C generated still (post-processed) → D library illustration → E Lottie (last resort). Enrichment budget: ≤2MB total. One enrichment archetype (E1–E8) + at most one polish pattern (HP1–HP4) per hero, never two polish patterns.
- Font catalog picks for a dark, technical, creator-facing product (all free, Google/Fontshare): Display — Bricolage Grotesque (variable, 800), Space Grotesk, Cabinet Grotesk, Clash Display, Tanker, Big Shoulders Display, Anton. Body — Switzer, General Sans, IBM Plex Sans, Geist. Mono/outlier — JetBrains Mono, Geist Mono, IBM Plex Mono, Commit Mono, Space Mono.
- Required font features: font-display: swap on every web font; size-adjust / ascent-override / descent-override / line-gap-override on fallbacks to prevent CLS; font-variant-numeric: tabular-nums on any column of numbers; oldstyle-nums in body where supported.

### Applied to Whetstone
- GENRE FORK — resolve before anything else. The brief fires modern-minimal ("platform", "founders", "Next.js/dashboard") AND atmospheric ("dark-first", "game devs", "video creators", "gamers"). Ask the one mandated follow-up. Recommendation: atmospheric, because dark-first is a stated constraint and atmospheric's theme cluster (Bloom / Midnight / Terminal / Aurora / Lumen) is dark-native, whereas modern-minimal's loosenings (#fff paper, zero-chroma neutrals) are useless to a dark-first product. Consequence to accept: under atmospheric, gate 6 loosens (a centred hero is permitted if the eyebrow or CTA still breaks axis) and gate 29 loosens (up to two fixed, unanimated radial blooms at ~20–30% footprint). Gate 2 (gradient text) and gate 22 (zero-chroma neutrals) stay fully enforced.
- SAY "lock the system" AFTER SURFACE 1. With 9 surfaces, the diversification rule must be inverted via a root design.md, or Discover, Project Detail, Dashboard, and Auth each get a different macrostructure, nav, footer, and theme. Build the landing page first, lock it, then build surfaces 2–9 deferring to design.md. Every subsequent surface's CSS stamp must reference the system, and Hallmark's audit verb flags a missing stamp on a design.md project as `major: missing system reference`.
- ANCHOR HUE 45° (ember/spark — a whetstone throwing sparks). One anchor, one accent, never purple/blue. Every neutral carries chroma ≥ 0.007 — gate 22 is enforced, not loosened.
