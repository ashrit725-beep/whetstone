# Archive

What the build looked like before the remodel, kept because `direction.md`
refers to it and because a design decision is easier to judge against the thing
it replaced.

- `globals.grit-index.css`: the Grit Index stylesheet. Cold blue-green ground
  `#141D20`, tempering-blue accent `#66ACE2`, one warm straw token, Archivo and
  Literata. Superseded by Paper & Ink; `src/app/globals.css` is the live one.

Nothing here is imported by the application. Deleting this folder changes
nothing about what ships.
